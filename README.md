# Исследование машинного сознания

Цель — сравнить дискретный автомат и обучение с подкреплением в задаче движения из A в B по разрешённой местности, с локальным восприятием, памятью и внутренними ресурсами. Теоретическая основа — работы из `Articles/Core`.

Работают пошаговая среда, алгоритмический робот и десять диагностических уровней. Из корня проекта запустите один из режимов на Python 3.12 или новее.

```powershell
python -m maze --visual
```

В окне выберите уровень и нажмите «Пуск». Один ход занимает 0,5 с. Видна карта памяти и окно восприятия. Переключатель полной карты меняет только вид наблюдателя. Доступны пауза и повтор со старта. Для этого режима нужен Tk, входящий в обычную установку Python для Windows.

```powershell
python -m maze
python -m maze --level 10-crossroads
python -m unittest discover -s tests -v
```

Первая команда проходит все уровни подряд, вторая — один выбранный. Обе работают без отрисовки и задержек. Сторонние пакеты для запуска не требуются.
