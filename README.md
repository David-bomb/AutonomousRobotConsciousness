# Исследование машинного сознания

Цель — сравнить дискретный автомат и обучение с подкреплением в задаче движения из A в B по разрешённой местности, с локальным восприятием, памятью и внутренними ресурсами. Теоретическая основа — работы из `Articles/Core`.

Работают пошаговая среда, дискретный автомат и обученная табличная SARSA. Команды запускаются из корня проекта на Python 3.12 или новее.

## SARSA

Сохранённая модель прошла 32 из 36 карт val и 10 из 10 карт test. Чтобы посмотреть её на валидационных картах со скоростью 0,5 с за ход:

```powershell
python -m maze.learning watch
```

Чтобы воспроизвести обучение на 90 картах train и выбор модели на val, укажите новую папку результатов. Запуск работает без графики и задержек.

```powershell
python -m maze.learning train --run tmp/sarsa-reproduction
```

Существующие уровни 01–10 закреплены за test. Итоговый результат уже сохранён. [Выборки, контроллер и протокол](docs/experiments/E-0001-sarsa.md) · [Обученная таблица](results/E-0001/run-02/policy.json) · [Исходы test](results/E-0001/test.json)

## Дискретный автомат

По умолчанию запускается исходный автомат D-0008. Для просмотра новой версии E-0002 на сложной валидационной карте выберите контроллер `resources`. Такой же параметр доступен для любой карты. [Разбор ошибок и проверка правил](docs/experiments/E-0002-automaton.md)

```powershell
python -m maze --controller resources --split val --level val-3-10 --visual
```

Параметр `--service-offset 2` повышает порог выбора заправки и ремонта на две единицы. Для прибавки в три единицы укажите `--service-offset 3`. По умолчанию прибавка равна нулю. [Сравнение порогов на сложных картах](docs/experiments/E-0003-service-offset.md)

```powershell
python -m maze --visual
```

В окне выберите уровень и нажмите «Пуск». Таймер между ходами установлен на 0,5 с. Видна карта памяти и окно восприятия. Переключатель полной карты меняет только вид наблюдателя. Доступны пауза и повтор со старта. Для этого режима нужен Tk, входящий в обычную установку Python для Windows.

```powershell
python -m maze
python -m maze --level 10-crossroads
python -m unittest discover -s tests -v
```

Первая команда проходит все уровни подряд, вторая — один выбранный. Обе работают без отрисовки и задержек. Сторонние пакеты для запуска не требуются.
