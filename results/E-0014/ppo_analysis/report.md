# Почему PPO теряет финиши

У выбранной на валидации PPO обнаружились две слабости. На сложном этапе она завершила 523 учебных эпизода без единого финиша. Затем в контролируемых развилках она почти одинаково распределяла вероятности ходов, когда уже увиденная роботом часть лабиринта указывала то левый, то правый путь. Выбор хода случайно по обученным вероятностям также дал ноль финишей на трёх стресс-сотнях.

## Какой опыт получила сеть

В каждом из 50 обучений было 73 728 физических шагов и 1 536 обновлений весов. Каждый из трёх этапов дал 24 576 шагов и 512 обновлений. При фиксированном бюджете шагов на больших лабиринтах успевает завершиться меньше эпизодов. В таблице учтены эпизоды, завершившиеся до смены этапа. В этапах 2 и 3 генератор также подмешивал карты предыдущих этапов.

| Этап учебной программы | Финиши во всех 50 обучениях | Обучения с нулём финишей | Финиши выбранной PPO |
| --- | ---: | ---: | ---: |
| Первый | 1 482 / 46 836 (3,16%) | 0 / 50 | 25 / 891 |
| Второй | 159 / 40 160 (0,40%) | 1 / 50 | 5 / 797 |
| Третий | 23 / 26 922 (0,085%) | 29 / 50 | 0 / 523 |

При обычной первичной валидации на одних и тех же 240 сценариях среднее число финишей выросло с 0,98 до 3,20. Улучшение получили 37 обучений, без изменения остались 7, ухудшение получили 6. Для выбранной сети на всех 24 000 новых сценариев привычных типов было 680 финишей. [Итоги по всем обучениям](summary.json) · [Архив итоговой проверки](../../E-0012/final-results.md)

## Контроль выбора хода

Одна и та же модель `ppo-v09-s4` исполняла либо самый вероятный допустимый ход, либо ход, случайно выбранный по вероятностям PPO, как при обучении. Контрольная стратегия выбирала равномерно среди тех же допустимых ходов. Для двух случайных режимов использованы три повтора каждой карты. Начальные ресурсы, восприятие и физика совпадают. Обе стратегии получали одну и ту же последовательность случайных чисел для каждой пары «карта, повтор».

| Карты и режим | Финиши / эпизоды | Посещён любой сервис | Посещены оба типа |
| --- | ---: | ---: | ---: |
| Стресс-сотни, максимум вероятности | 0 / 300 | 66 | 8 |
| Стресс-сотни, выбор по PPO | 0 / 900 | 107 | 5 |
| Стресс-сотни, равномерный выбор | 0 / 900 | 62 | 1 |
| Привычные карты, максимум вероятности | 18 / 400 | 122 | 61 |
| Привычные карты, выбор по PPO | 36 / 1 200 | 303 | 84 |
| Привычные карты, равномерный выбор | 29 / 1 200 | 221 | 60 |

Привычные карты здесь — первые 100 рисунков стен из прежнего `test_id`, с четырьмя сценариями на каждый. Все 700 результатов детерминированного режима повторили архивные исходы, число шагов и посещений обоих типов сервиса. При выборке по PPO сеть на стресс-картах чаще достигала первого сервиса, чем при равномерном выборе. В пределах этих трёх повторов это не дало финишей. Контроль измеряет одну выбранную модель, повторные поездки по одной карте зависят от её устройства. [Покартовые результаты по режимам и сводка](summary.json) · [Код воспроизведения](check_ppo.py)

## Что определяло выбор на развилке

В 25 парах из отдельного контрольного банка (группа 4) робот видел одинаковое окно 3×3 и имел одинаковую позицию, запасы, показания датчиков и предыдущий ход. Различалась только записанная в памяти карта. На этих задачах сохранённая преграда определяет, по какому из двух направлений проходит дорога. Оба верных направления на каждой паре противоположны. Эталон определяет внешний оценщик. На вход политики эталон не подаётся.

| Признак, изменившийся в паре | Основная PPO, пар со сменой хода | Основная PPO, верных ходов | После обучения на диагностических примерах, пар со сменой хода | После обучения, верных ходов |
| --- | ---: | ---: | ---: | ---: |
| Карта памяти, группа 4 | 0 / 25 | 25 / 50 | 0 / 25 | 25 / 50 |
| Только запас топлива или исправности, группа 6 | 3 / 25 | 22 / 50 | 12 / 25 | 37 / 50 |
| Полностью одинаковое наблюдение, группа 11 | 0 / 25 | 25 / 50 | 0 / 25 | 25 / 50 |

В группе с различимой преградой медианный перенос вероятности между действиями при изменении карты памяти составил 0,0039 процентного пункта у основной сети и 0,00060 процентного пункта у дообученной. Измерена половина суммы абсолютных разностей вероятностей. В группе с изменением запаса основная PPO во всех трёх случаях смены хода ошиблась в обоих сценариях пары. После дополнительного обучения все 12 переключений соответствовали изменению нужного направления. На шаблоне U-образного обхода число полных финишей выросло с 1 до 49 из 50. На развилках группы 4 оно упало с 10 до 0 из 50. Это ограничивает вывод, который можно сделать по общему росту на двадцати шаблонах с 376 до 685 финишей из 1 000. [Парные ответы, вероятности и результаты всех групп](probes.json) · [Код проверки](probe_ppo.py)

## Проверка обновлений

Рабочая реализация сохраняет 16 последовательных шагов для каждого из 24 одновременных роботов. Посчитанные преимущества сохраняют порядок шага и робота при сопоставлении с командами. Для каждого завершённого эпизода коэффициент продолжения равен нулю. Если обрывается только блок сбора, расчёт использует оценку состояния в следующем наблюдении. Два прохода по 384 образцам, пакетами по 96, дают восемь обновлений на блок. Сверка с независимой прямой суммой преимуществ для 48 позиций, с раздельными концами эпизодов и обрывом блока, дала максимальную абсолютную ошибку 8,9 × 10⁻¹⁶. [Реализация обучения](../../../neural_rl/training.py) · [Проверка границ эпизода](check_ppo.py)

Данные подтверждают редкость положительных исходов на сложном этапе и слабое использование карты памяти в измеренных развилках. Для разделения влияния награды, архитектуры и числа учебных шагов потребуются обучения, где эти условия меняются по одному.
