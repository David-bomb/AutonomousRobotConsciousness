## Протокол

Фиксация развёртывания состоялась 27 ноября 2026 года в 17:32 по Москве. Решение директора ссылается на SHA-256 отборочного результата `632a75895e3cf630c9b650a9066618c3f420426e1fe86000a46970480cecf8c9`. Перед регистрацией пройдена повторная сверка всех 800 отборочных поездок. Для B сохранены 24 файла исходников и библиотек с хешами отборочного снимка. Два независимых синтетических запуска дали одинаковую последовательность из семи действий. [Решение](director-plan.json) · [Регистрация](registered.json) · [Проверка поставки](chain.json)

Оценщик сверяет три оригинальных банка с двумя историческими манифестами, включая геометрии, исходные запасы и ограничение числа шагов. Для каждой карты он запускает отдельный процесс, передаёт байты весов, затем только штатные наблюдения. Первый вызов начинается с двух пустых регистров. При каждом последующем вызове политика получает расстояния до F и R с предыдущего реального наблюдения. После выбора хода исполнитель проверяет обновление обоих регистров, а среда применяет ровно одну команду. Счётчики команд и SHA-256 независимо ведутся с обеих сторон канала. [Предрегистрация](registration.md) · [Исполнитель политики](worker.py) · [Оценщик](run.py)

Файлам сценариев и журналам закрыт доступ через Python в процессе политики. Библиотеки DLL исполняются как доверенный код, закреплённый контрольными суммами и проверенный по имеющимся исходникам. Это ограничивает гарантию изоляции проверенным комплектом. На этих сотнях уже оценивались прежние кандидаты проекта. Независимый перенос на новые геометрии требует отдельного подтверждающего испытания.

## Как перепроверить квитанцию

Из корня Diplom запустите команду ниже. Она заново сверяет развёртывание и состав трёх сотен, проверяет расположение робота, запасы и оба счётчика сервиса по каждому сохранённому действию. Затем она проверяет общий результат и вычисляет воспроизводимый SHA-256 канонического журнала. В него входят все поля поездки, кроме идентификатора процесса, который назначает Windows. Контрольная сумма исходной квитанции отдельно связывает результат с конкретным запуском.

```powershell
& .\venv\Scripts\python.exe -B -X utf8 results/verification-rl80/wave3-conservative/seal.py
```
