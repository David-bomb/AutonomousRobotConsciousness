## Воспроизведение

Вес после RL — `results/E-0016/runs/recovery800/rl.pt`, SHA-256 `020574084dcfaa3efffca38d0c057419e0e90307548f06bfb62acad5be47946f`. Единственный банк поездок — 100 карт `dev.jsonl` с SHA-256 `4ce3fcd9106332497bf6a6e6ad26040aae303fc297a77dc7606828c5edabe8a6`. Канонический SHA-256 регистрации — `c39f348a742f579bc28d23bf5b126739c29bef6f29b9e8a29a577f20a0d5fc38`. [Регистрация](recovery800-dev/lock.json) · [Спецификация dev](dev-spec.json)

Рабочий адаптер E-0016 был расширен после исходной оценки. Для воспроизведения восстановлен исходный `adapter.py`, чей SHA-256 `782f5b786d41f3d44a7eb68e901146e43026df9a8ec3d840b133238d63528159` совпал с физическим журналом запуска. Скопированные `policy.py`, `geometry.cpp` и `geometry.dll` совпали по SHA-256 и с конфигурацией обучения, и с физическим журналом. Обёртка передаёт исходному загрузчику точные байты весов через временный файл. Каждая карта получает новый процесс контроллера на CPU с одним потоком PyTorch, чистую память и штатные начальные запасы. На каждом такте оценщик передаёт только `Observation` и один раз вызывает `Environment.step` для возвращённой команды. [Снимок адаптера](recovery800-dev/frozen/adapter.py) · [Обёртка](recovery800-dev/bridge.py) · [Происхождение файлов](recovery800-dev/provenance.json)

Для валидации использовано сохранённое при подготовке спецификации свидетельство об отсутствии пересечений. При загрузке заново пересчитаны геометрии, исходные запасы, сценарии и отпечатки кода среды. Контроль чтения этой ветви оценщика зарегистрировал только файл dev, его спецификацию, регистрацию кода среды E-0015 и шесть исходников среды. I/II/III и confirmation при этой проверке оставались закрыты.

Повторная сверка сохранённых журналов из корня проекта занимает две команды. Первая проверяет регистрацию и пересчитывает итог. Вторая сопоставляет записи независимого и исходного прогонов по ID карты.

```powershell
$py = '.\venv\Scripts\python.exe'
$v = 'results/verification-rl80'
$r = "$v/recovery800-dev"
& $py -X utf8 -B "$v/evaluate.py" verify --lock "$r/lock.json" --lock-sha256 c39f348a742f579bc28d23bf5b126739c29bef6f29b9e8a29a577f20a0d5fc38 --out "$r/independent"
& $py -X utf8 -B "$r/compare.py"
```

Для нового физического воспроизведения та же команда `evaluate.py` принимает `run` и путь к новой выходной папке. Исходная запись содержит терминальный исход, число ходов и оба счётчика сервиса для каждой карты. Независимый журнал дополнительно сохраняет SHA-256 последовательности команд. Исходный журнал такого отпечатка не содержит, поэтому покомандное совпадение двух поездок остаётся непроверенным.
