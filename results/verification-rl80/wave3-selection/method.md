# Независимый отбор на двух учебных сотнях

Каждый из сидов 9167001 и 9167002 дал ровно 100 различных геометрий. Между сотнями совпадений 0. Проверка исключила 101 164 ранее известных геометрии. В этот реестр вошли три исходные сотни, первичные и дополнительные банки E-0016, dev и 200 карт confirmation, геометрии факторного опыта, предыдущая phase100 и дополнительные учебные банки лаборатории. Для закрытых наборов изолированный процесс извлекал канонические SHA-256 стен из зарегистрированных полей. Для I–III дополнительно сверялся отпечаток исходного файла, для dev и confirmation — отпечатки и численность в официальной регистрации. Совпадения определялись с точностью до поворота, отражения и перестановки меток. Оценщик получает только файлы двух новых сотен. [Реестр исключений и отпечатки банков](bank-receipt.json) · [Изолированный проверяющий](banks.py)

Четыре снимка весов и весь используемый локальный код зафиксированы до измерения. SHA-256 файла регистрации — `120b41ef469782fef4ee6ee45500a9585486ffe8088830cfcccc93cb5b5178a3`. Адаптер B непосредственно проверяет сохранённый в весах порог 0,9. Загрузчиками C и D служат `tree_policy.load(bytes)` и `panel_policy.load(bytes)`. Путь поиска Python содержит проект Diplom и каталог лаборатории. Первыми в нём стоят копии исходников и DLL из регистрации. Для модулей E-0016 и лабораторных политик проверялись фактические пути загрузки. [Предрегистрация](preregistration.md) · [Контроль источников](source-check.json) · [Закреплённые файлы](lock.json)

Для каждого метода выделен изолированный процесс на CPU. На каждой карте он загружает новый экземпляр контроллера из тех же байтов весов, очищает геометрические кэши и начинает с двух пустых регистров. Перед вызовом `choose` проверяется пара показаний прошлого физического шага. Сразу после вызова проверяется её замена текущими показаниями. Каждый физический шаг получает одно решение от сети. Штатный кэш ответа внутри карты использует всю пару «наблюдение, два предыдущих показания». Доступ к проектным данным ограничен. В процесс не поступают название карты, сид, истинное поле или подсказки симулятора. [Исполнитель политики](worker.py) · [Среда и журнал](run.py)

В журнале каждого эпизода сохранены действия, последовательность ранних и поздних решений, исход, шаги, заправки, ремонты и SHA-256 команд. Хеш берётся от байтов со значениями 0–7 в порядке N, E, S, W, NE, SE, SW, NW. Раскрытие полных окон F и R, первый вызов позднего контроллера и первое фактическое получение обоих сервисов считаются отдельно. Для A, C и D позднее решение требует раскрытых окон и выполнения условия запаса `−101`. Для B условием передачи служит раскрытие окон. Порог 0,9 у B определяет принятие поправки к раннему действию.

Повторная проверка физически воспроизводит только записанные команды двух отборочных сотен. Веса, исходы, переходы между фазами, четыре вектора итогов и приоритет при равенстве сверяются с регистрацией. Историческая волна относится к отдельному решению директора. [Проверка и выбор](verify.py)
