# Самостоятельные поездки обычной mission600/rl на dev

**36 финишей из 100**, по группам H1–H4 соответственно **17/25, 9/25, 8/25 и 2/25**. На каждой карте независимый CPU-прогон воспроизвёл все четыре поля исходного физического журнала — исход, число ходов, заправок и ремонтов. В совокупности 58 065 физических ходов, 2 108 заправок и 1 856 ремонтов. Оба типа сервиса посещены на 52 картах. Из 64 неудач 31 поездка завершилась исчерпанием топлива, 25 — исчерпанием исправности, восемь — достижением лимита. [Результат сверки](receipt.json) · [Независимые поездки](independent/episodes.jsonl) · [Исходный журнал](rl.physical.json)

Запуск использует исходную модель `SequenceNet` и только штатное наблюдение. Рабочий адаптер впоследствии расширили для другого класса сети. На каждой карте новый процесс контроллера получает только `Observation`. Оценщик запрашивает команду и выполняет `env.step` на каждом такте, включая все повторения до терминального исхода. После завершения сводка сформирована из 100 покартовых записей в порядке зафиксированного dev. Исходный журнал предоставляет четыре сопоставленных поля. Хеши последовательностей ходов записаны независимым оценщиком. Для этой модели область проверки ограничена dev. [Спецификация](../dev-spec.json) · [Исполнение и сверка по ID](check_dev.py)
