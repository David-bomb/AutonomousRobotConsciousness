Это подготовленный план. Обучение моделей не запускалось; корпус лабиринтов ещё не сгенерирован. Готового trainer и реализации среды в архиве нет.

experiment_space.json — определения признаков, сетей, наград и правил сочетания.
full_grid.jsonl.gz — все 47 520 структурно допустимых сочетаний указанной дискретной сетки; одна JSON запись на строку после распаковки gzip.
screening_96.jsonl — первая выборка из 96 конфигураций, включая 12 опорных вариантов; покрывает 563 из 563 допустимых пар значений факторов (100.0%). Полного покрытия тройных и более сложных взаимодействий этот набор не обещает.
extended_experiments.json — 50 дополнительных исследований вне основной сетки.
corpus_spec.json — генераторы, разделы, объёмы, схема задач и траекторий.
parameter_examples.json — точные арифметические подсчёты одного семейства CNN; это не проверка обучаемости сети.

Основной реестр предполагает, что dS относится к объекту, восстанавливающему топливо. Если датчик сообщает ближайшую мастерскую, которая не заправляет, R4/R5/R6 и топливные интерпретации признаков требуют пересмотра или деактивации. Не заменять этот датчик недоступным расстоянием до заправки.
LocalMLP по определению использует F0/F1. FlatMapMLP существует как отдельный эксперимент E01; ограничение основной сетки не означает математической невозможности MLP по карте.
Каждая запись — гипотеза. Совместимость конкретной реализации, формы тензоров и фактическое число параметров проверяются после сборки модели. Никакие результаты и обученные веса не представлены.

Сначала читать документ rl_maze_experiment_plan.docx. Идентификаторы факторов в документе совпадают с JSON. Дополнительные экспериментальные ID используют отдельные имена групп и не являются ID full_grid.
