# Вторая волна E-0016

Цель и набор dev прежние. Первую волну завершаем выбором одного post-RL чекпойнта по ранее зафиксированному правилу. Эта запись оставляет её результат доступным при дальнейшем обучении. Новые попытки получают отдельные веса и покартовые исходы.

## Что получает сеть

На тех же восьми действиях представлены длины и минимальные остатки по последовательностям B, F→B, R→B, F→R→B и R→F→B. Через каждый первый ход сравниваются варианты выбора станции каждого типа. Оценки рассчитаны по известным дорогам и трём предположениям о неизвестной области. Для открываемых из уже осмотренных клеток окон представлены длины до такой границы и возможность вернуться через сервис одного или обоих типов. Учитываются также маршруты к границе с промежуточным обслуживанием. Оценки длины через неизвестную область могут ошибаться. Ни один рассчитанный показатель сам не назначает действие. Исходные маска допустимости и физический канал наблюдения сохранены.

Отдельная обучаемая часть предсказывает для каждого легального хода, уменьшится, сохранится или увеличится показание до заправки и до ремонта. На train внешний наблюдатель размечает все легальные действия по геометрии. При самостоятельном управлении доступны два исходных показания, известные клетки и собственный прогноз сети. На отдельной сотне новых учебных геометрий (`probe`) измеряются доля верно предсказанных знаков и доля выбранных по прогнозу направлений, действительно уменьшающих показание при запасе минус длина ≤3. Сравнение — равномерный выбор из легальных ходов в тех же состояниях. В отбор весов входят только полные поездки dev.

## Порядок

1. Отдельно закрепить 1 600 дополнительных train и 100 probe с исключением прежних геометрий по всем восьми ориентациям. Сначала использовать 600 новых геометрий. Демонстрации `frontier-reserve` собрать только на 100 геометриях исходного нового train. Ограничение 260 ходами относится к сбору примеров. В подвыборке обычных траекторий смешать оптимальные действия с отклонениями, ограничить сбор 180 ходами. Участвуют и восприятия, из которых финиш уже потерян, для них обучается только прогноз датчиков.
2. Инициализировать основную оценку действий от зафиксированной первой волны. Добавить новую оценку действия с нулевым начальным вкладом. Учить прогноз знака из собственных неполных карт, совместно учить выбор по разметке успешных маршрутов и по действиям частично наблюдающего учителя на train. Этапы на 3 и 8 эпохах сравнить на полном dev. При равенстве выбрать более ранний вариант, приоритет — число финишей и затем минимум по четырём сложностям.
3. Дополнить выбранное обучение собственными полными поездками за терминальный SUCCESS. Сопоставлять на одной учебной карте жадный и случайный проезд тех же замороженных на время сбора весов. Записывать число вновь достигнутых и потерянных финишей. После обновления измерить dev вновь. На каждой карте оценки полный старт и каждый ход через Environment.step.
4. Разобрать до и после первого сервиса, после обоих обслуживаний и на тупиковых участках, прежде чем менять состав следующих учебных данных. Для допуска к подтверждению действуют прежние пороги. Три раскрытые сотни остаются у независимого оценщика.

## Уточнение после 36/100 на dev

Следующий запуск использует 1 600 учебных геометрий и 400 поездок с разведкой. Иногда внешний наблюдатель на train возвращает учителя к успешному пути, если тот собирается сделать необратимый ход либо 16 ходов подряд не видит новых клеток. В 359 поездках получен физический SUCCESS. В демонстрациях удалены только возвраты в ту же позицию с прежней памятью, когда оба запаса ранее были не меньше. Физический повтор подтвердил все укороченные поездки. Политика учится на равномерных по геометрии и этапу примерах успешной разведки, на штатном прогнозе остатка после каждого действия и на известном выполнимом пути к финишу, если он уже представлен в памяти. Последнее используется только для учебной разметки. Закреплены контрольные точки после 1 200 и 3 200 обновлений, далее восемь групп парного RL по SUCCESS, полный dev и разбор train.
## Продолжения с альтернативной первой командой

На 240 геометриях дополнительного train с равным представительством H1–H4 сравниваются все легальные первые команды на выбранных развилках. С одной и той же позиции, с одной памятью клеток и запасами каждое продолжение исполняется до штатного терминала. После первой команды управляют фиксированные веса mission600. Для каждого первого действия есть один детерминированный повтор и один стохастический при температуре 0,6. Статистика выдаёт осуществимость финиша при этих продолжениях, а не при всезнающем управлении. Для отбора учебных примеров отдельно включены развилки до заездов, после первого и после обоих видов обслуживания, обратимые и первые необратимые выборы самой сети. Дополнительные послесервисные префиксы приходят из физически успешных train-демонстраций. Самостоятельные продолжения обходятся без учителя. Оценку ожидаемой терминальной награды учим только на train. При отборе снова воспроизводим обычные физические поездки на dev. Вход политики по-прежнему одно текущее наблюдение.
## Пространственный прогноз и новые учебные геометрии

После проверки реальных продолжений сравниваются две возможности улучшения. Для выбора после заезда сеть получает по каждому первому направлению длины до границы уже открытых дорог, оставшиеся запасы и оценку маршрута от этой границы до B с возможными F и R. Измеряются варианты с подтверждаемым возвратом к обоим сервисам, к одному сервису и с предполагаемым продолжением без гарантированного возврата. Для защиты запасов новая сеть предсказывает изменение текущих показаний отдельно по каждому физическому действию. Таблицы вероятности неизвестных клеток обучаются на новых геометриях train. Суммирование весов возможных путей использует память и только два текущих показания, действительные показания соседних позиций не запрашиваются. На полностью раскрытых учебных геометриях отдельно проверена совместимость указанных направлений с физикой.

Отдельная свёрточная сеть видит типы клеток, координаты и видимые участки дорог за каждым физическим направлением. Сначала для 800 train подготовлено 204 800 синтетических снимков. Память открыта окнами вдоль связного участка дорог. Произвольная позиция и размер открытого участка упрощают получение примеров для прогноза датчиков. Здесь не воспроизводятся начальные запасы и поездка от A, а SUCCESS по синтетике не измеряется. На отдельной учебной сотне probe были сопоставлены две контрольные точки вспомогательной сети, затем для продолжения закреплена точка 2 200. Второе обучение смешивает эти примеры с настоящими снимками учителя на 400 геометриях и собственных поездок на других 400 геометриях. Для этой стадии зафиксировано 1 800 обновлений, качество датчиков на реальных probe служит диагностикой.

Для следующих сравнений закреплены дополнительные 3 200 учебных геометрий и 200 отдельных учебных стартов для выбора коэффициентов по полному терминальному SUCCESS. Пересечения со всеми прежними геометриями исключены по инвариантному отпечатку стен. Из старых контрольных файлов для этой сверки извлечены только отпечатки, их полный набор совпал с хешем исходной регистрации E-0016. Итоговая dev остаётся той же сотней, две подтверждающие сотни зарезервированы. [Манифест новых данных](spatial/fresh.json)
