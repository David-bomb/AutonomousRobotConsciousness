# Опыт исключён из сравнения

Первоначальная сборка учила голову с использованием истинной координаты A из учебного файла. В штатной памяти клетка старта отображается как дорога, отдельная метка A отсутствует. Изолировать этот вход на реальной поездке не удалось. Адаптер завершился исключением при первом обращении к отсутствующей метке, полных результатов dev у этих весов нет. Артефакты оставлены для воспроизводимости ошибки. Контрфактические разъезды field3200 собирались без координаты A, поэтому те же физические исходы использованы в новом обучении головы только по доступным наблюдениям.
