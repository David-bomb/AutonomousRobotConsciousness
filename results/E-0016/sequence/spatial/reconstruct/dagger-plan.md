# Дополнительное обучение на собственных поездках

На 153 чувствительных критических развилках вспомогательной выборки маргинализация дала 118 жизнеспособных ходов, отключение пары — 107. Регистрируем дополнение до получения полных результатов dev. Для обучения используем large[7600:7800], для отдельного физического отбора — large[7800:7900]. В каждой сотне по 25 геометрий H1–H4. Первые 200 карт дают снимки при движении уже обученного односнимкового варианта с маргинализацией. На половине карт учебный проверяющий может дважды исправить необратимый ход для получения примеров дальнейшего восстановления. При оценке доступен один обычный снимок.

Обучаем сеть на смеси прежних и собственных поездок. Прежние и новые данные получают равный вес пакетов. Используем девять классов обратного изменения и восемь прямых оценок. При утрате достижимости хода ранней сети прямой выход учится предпочитать доступное жизнеспособное продолжение по меткам train. Для усреднения проверяем ожидаемую оценку и ожидаемую вероятность физического хода. Два первых кандидата — лучшая ранее зарегистрированная политика и дообученная маргинализация. Затем идут дообученный прямой выход и усреднение вероятностей при температуре 1. Выбираем по финишам на отдельной сотне, затем по слабейшей сложности, затем по указанному порядку. До самостоятельного dev фиксируем веса и победителя. При выборе прежних весов воспроизводим их опубликованные полные результаты.
