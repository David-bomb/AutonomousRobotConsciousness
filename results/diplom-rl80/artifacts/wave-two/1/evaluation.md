[Предрегистрация](registration.md) · [Запись до контроля](registered.json) · [Состав поставки](lock.json)

Исходный загрузчик на CPU принимает байты модели. Проверены значения, формы и типы всех 55 тензоров ранней компоненты wave1 и 85 тензоров поздней joint400 относительно файлов, закреплённых их манифестами. Пороги равны `[9,9,-101]`. Точка входа перенаправляет два импорта в собственную копию зависимостей. Поздняя компонента включается, когда в памяти полностью раскрыто окно 3×3 вокруг хотя бы одной заправки и одного ремонта и выполнено условие запаса. Остальные решения принимает ранняя компонента с двумя предыдущими фактическими показаниями. При любом выборе обновляются оба регистра. [Исходный загрузчик](frozen/service_window_policy.py) · [Проверка компонентов](chain.json) · [Веса](frozen/model.pt)

Проверку состояний среды и результата каждого эпизода можно повторить в проектном окружении из корня Diplom. Она заново проверяет регистрации, геометрии, исходные запасы, SHA-256 сырых байтов действий, первый терминальный исход и оба счётчика сервиса. Проверка обрабатывает записанные команды без запуска политики.

```powershell
$dir = 'results/verification-rl80/wave2-service-window'
& .\venv\Scripts\python.exe -X utf8 -B "$dir/run.py" verify 3f7d6457f3b1d3de66e7c48dbb5882db555c9d67e2f33df61c20aed7347054cc
```

Для подключения модели в репозитории используется следующий вызов в новом процессе для каждой карты.

```python
from importlib import import_module
from pathlib import Path

package = "results.verification-rl80.wave2-service-window.bridge"
data = Path("results/verification-rl80/wave2-service-window/frozen/model.pt").read_bytes()
controller = import_module(package).load(data)
assert controller.previous == (None, None)
move = controller.choose(observation)
```

Эталонный симулятор работает в родительском процессе. У процесса политики своя временная рабочая папка. По каналу поступают веса и поля `Observation`. Проверяется пустая пара непосредственно после загрузки, сохранённая пара перед каждым решением и обновлённая пара после него. Хук Python ограничивает открытие проектных файлов данных и сетевые подключения. Защита опирается также на проверенные исходники и закреплённые штатные DLL.
