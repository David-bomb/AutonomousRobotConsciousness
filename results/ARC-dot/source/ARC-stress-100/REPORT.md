# Стресс-тест: 100 новых лабиринтов

Зерно генератора: `20318577`. Python 3.12.14. SHA-256 файла карт: `ea09b467f486a64ffcabe20086c632da27c9c431e55d017be2732174971ef899`.

Геометрии различны даже с учётом поворотов и отражений. Не было пересечений с 536 отпечатками из прежних сохранённых прогонов. Ровно по 25 карт каждого типа: коридорные, ветвистые, с петлями и с комнатами. Ни один из двух начальных ресурсов не позволяет доехать до финиша без пополнения своего типа; внешним поиском проверена разрешимость всех 100 и найдена минимальная длина легального успешного маршрута. Полная карта не подавалась контроллерам.

## Ограничения стенда

Версии frontier, frontier-reserve и A–F извлечены из сохранённого патча и сверены по SHA-256. Рабочая папка исходного репозитория оказалась недоступна. Пилот, ресурсный автомат и базовая физика восстановлены из ранее прочитанного кода; это не повтор с проверенной копией исходного коммита. Замороженная SARSA и архивный ресурсный автомат E-0002 r1 не проверялись: их точных исходников или весов нет в сохранённом пакете. Это пропуски, а не нулевые результаты. Доступ к GitHub не использован.

Счётчики эпизодов с точным повтором наблюдения и полного состояния контроллера доведены до штатного лимита повторением доказанного цикла. В `episodes.csv` указано число таких ходов; `--no-acceleration` исполняет каждый ход. Параметры контроллеров не менялись по этим картам.

## Как воспроизвести

Извлечь архив. Файл `maps.jsonl` содержит точные карты. Полная версия команды ожидает базовый проект с ранее выданным патчем frontier-auto; на включённой восстановленной копии `stand-reconstruction` возможен только режим `--partial-run`.

```sh
python make_hard_maps.py new-maps.jsonl --exclude excluded.json
python run_benchmark.py stand-reconstruction maps.jsonl new-run --partial-run
python summarize.py new-run/episodes.csv new-run
```
