# T-0002. Нейронное обучение для ресурсной навигации

По запросу пользователя от 26.11.2026 серия E-0011 включает по 50 обучений в каждом из пяти семейств. Внутри каждого семейства проверяются разные архитектуры и параметры обучения. Для конфигураций и результатов выделена папка `results/E-0011/`.

1. Установить PyTorch в подготовленное окружение. Проверить свёртку, обратное распространение ошибки и обновление весов на GPU.
2. Подготовить отдельные серии Double DQN + CNN, Dueling Double DQN, Rainbow DQN, PPO + CNN и иерархического RL с A*. Для первых четырёх агент выбирает физический ход. Для пятого обучаемая часть выбирает промежуточную цель, A* ищет путь по известным клеткам. На входе доступны окно 3×3, разрешённая память клеток, внутренние показатели и сведения варианта A. [Архитектура](../architecture.md)
3. До обучения зафиксировать наборы карт, конфигурации, начальные значения генераторов случайных чисел, бюджет обучения и правило отбора по val. Обучать на train от простых карт к сложным, сравнивать на val всех сложностей. [Разделение выборок](../decisions/0009-sarsa-splits.md)
4. Для каждого из 250 завершённых обучений сохранить фактическую конфигурацию и результаты оценки. Сопоставить долю финишей, число ходов и причины неудач.

## Результат

Завершено. По уточнению пользователя использован `venv` в корне проекта. PyTorch 2.8.0+cu129 выполнил 250 обучений на GeForce RTX 3050 Ti Laptop GPU. Сохранены все веса, конфигурации и 9000 покартовых результатов val с контролем начальных весов. У пяти отобранных моделей повторены все 180 поездок.
