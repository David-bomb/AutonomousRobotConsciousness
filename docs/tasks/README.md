Создавать отдельную карточку, когда задача продолжается несколько сессий или имеет несколько зависимых этапов с проверками. Формат имени: `T-0001-short-name.md`; [шаблон](../templates/task.md). Небольшим правкам и обсуждениям отдельная карточка не нужна.

В карточке должны быть цель, критерий готовности, ограничения, этапы, подтверждённый прогресс и следующий конкретный шаг. Завершённую карточку сохранять со статусом «Завершено» и ссылкой на результат. `status.md` содержит ссылку на текущую карточку, а не её полную копию.
