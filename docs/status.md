## Где остановились

Для первого опыта выбран **A** с доступом ко всей накопленной карте типов. Перед выбором одного из восьми направлений автомат и RL получают смещения Dx и Dy до B и два минимума по длине пути из текущей клетки до сервисов: один для заправок и один для мастерских. Подсказки следующего хода отклонены. [Состав входа](architecture.md) · [Решение D-0007](decisions/0007-agent-map-and-service-distances.md)

Для малого поля предложены точная запись карты в ключе и SARSA(0). В [примере развилки](concepts/tabular-rl-at-a-fork.md) проверены числовые обновления на двух заданных маршрутах. Выбор метода и самостоятельное обучение остаются впереди. **D** остаётся предметом обсуждения. [Память и границы решений](concepts/memory-and-decision-boundary.md)

Если таблица Q выбирает действие по `(x,y,fuel,health)`, длины путей на постоянной карте определяются уже известной позицией, а память не участвует в выборе. Такой первый опыт не доказывает пользу памяти и перенос на новые карты. Для C недостаточно только добавить неиспользуемое поле карты во вход.

## Следующий содержательный шаг

Определить награду и кодирование карты для первого табличного контроллера, затем проверить его на фиксированном уровне через тот же интерфейс. Параметры пилота доступны в [D-0008](decisions/0008-maze-pilot.md). Уровни 07–10 проверяют выбор бокового проезда к сервису при изменении ресурса. На уровне 07 проверен выбор между двумя запомненными дорогами к заправкам. [Открытые вопросы](questions.md)
