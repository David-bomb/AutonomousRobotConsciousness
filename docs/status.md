# Текущее состояние

**27 ноября 2026 года. Исследование на паузе по указанию пользователя.** Цель E-0016 — минимум 80 физических финишей на каждой из трёх исходных стресс-сотен у одной замороженной модели. Лучший официальный результат wave3-conservative — **73/100, 71/100 и 67/100**. Предыдущие регистрации дали 73/70/67 у wave2 и 28/25/20 у wave1. [Сводка моделей, условия и квитанции](../results/E-0016/handoff.md#независимые-проверки-на-исходных-сотнях)

На общей сотне разработки protected-search/learned с двумя предыдущими показаниями завершила **80/100** поездок, по H1–H4 — 24/22/20/14. Оба вида сервисов посещены в 86 поездках. При пустых предыдущих показаниях те же веса дали 52/100. Лучший результат основной серии, где аппарат принятия решений получает только текущий снимок, — **60/100** у field3000-clean. [Поездки и замороженные веса](../results/E-0016/handoff.md#разработка-на-общей-сотне-dev)

## Точка продолжения

Новый отбор восьми сочетаний политик по двум учебным банкам приостановлен до определения победителя. Двести геометрий независимого подтверждения закрыты. В односнимковой ветви reconstruct завершены обучение на собственных поездках и парные физические проверки. Дополнительная проверка прогноза прошлых показаний с исключённым направлением к B остановлена до обучения. [Точка паузы E-0016](../results/E-0016/handoff.md#точка-паузы)
