# Термины проекта

Это рабочие значения терминов, а не новые определения авторов Core. Основания и более подробное обсуждение — в [конспекте Core](../Articles/Core/main_ideas.md) и [общем синтезе](../Articles/main_ideas.md).

| Термин | Как используем в проекте |
|---|---|
| Минимальное машинное сознание | Функциональный контур восприятия, учёта своего состояния, принятия решений и действия с обратной связью |
| Аппарат принятия решений | Часть системы, которая по доступным сведениям выбирает действие; в исследовании реализуется автоматом или RL |
| Внутренние показатели | Сведения о собственном состоянии робота; в обсуждаемых примерах — топливо и исправность |
| Потребность | Основание изменить поведение, например необходимость заправиться или отремонтироваться; в D1 робот выбирает «к B», «заправиться» или «отремонтироваться» |
| Расчёт длин в A | Источник одинаковых сведений: по полной сети сообщает длины путей из текущей фактической позиции. Не выбирает ход и не отвечает на запросы из воображаемых соседних позиций |
| Навигатор, выбирающий ход в D | Заранее написанная часть аппарата принятия решений после выбора потребности. Не относится к физической среде; ограничивает обучаемую часть решениями о потребности |
| Длина пути | Длина кратчайшего разрешённого маршрута; в примерах — число ходов. Равный учёт прямых и диагональных ходов пока предложен, но не утверждён. Отдельный показатель «стоимость» не вводится |
| Агент исследования | Робот/контроллер в моделируемой среде; не путать с Codex, который помогает вести проект |
| Состояние среды `s` | Все переменные, определяющие динамику симулятора; не обязательно доступны контроллеру |
| Наблюдение `o` | Сведения, которые агент получает на текущем шаге |
| Окно 3×3 | Ограничение локального внешнего восприятия; не автоматически ограничение объёма памяти |
| Пространственная память `M` | Сохранённые типы клеток и, если выбраны, посещения; состав ограничен REQ-007 |
| Вход контроллера `z` | Выбранное представление наблюдения, внутреннего состояния, доступной памяти, цели и сервисов |
| Неизвестная клетка | Её тип не сообщён; не равна подтверждённому препятствию |
| Посещение | Фактическое нахождение/прибытие в клетку по выбранному правилу счёта; наблюдение соседа само по себе им не является |
| Сервис | Заправка или мастерская; положение известно постоянно. Путь может отсутствовать; при наличии дороги общий навигатор может её найти. Что он сообщает роботу, зависит от варианта |
| Переход | Допустимое перемещение между клетками; отдельное хранение рёбер сейчас исключено |
| Обратная связь действия | Сведения о фактическом исполнении команды; команда не обязательно равна перемещению |
| Состояние автомата `q` | Текущий режим управления; не тождественен полной карте или состоянию мира |
| Политика | Правило или распределение, определяющее выбор действия по доступной информации |
| Q-функция | Оценка ожидаемого результата выбора действия при заданных условиях дальнейшего поведения |
| Параметры обучения | Сохраняемый результат обучения; отличаются от карты памяти отдельного эпизода |
| Эпизод | Один запуск задачи с определёнными начальными условиями и правилом завершения |
| Абляция | Сравнение с исключением компонента, например посещений, при контроле остальных условий |
| Журнал эксперимента | Запись для исследователя; её содержание не становится доступным роботу автоматически |
| Самопознание / самонаблюдение / самосознание / самоинформирование | Термины Core для функциональных свойств; проектные проверки требуют отдельной операционализации |

Топливо не называется эмоцией автоматически, а RL не называется подсознанием по одному типу алгоритма. Полное состояние симулятора, доступная карта памяти и выученные параметры нужно различать и в тексте, и в будущих интерфейсах.
