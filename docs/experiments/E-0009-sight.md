# E-0009. Помогает ли роботу осмотр конкретной неизвестной клетки

25.11.2026. Проверяем предложение из E-0008: пока ещё хватает ресурсов вернуться, робот может осмотреть клетку, от которой зависит выбор дороги к сервису. Есть два разных критерия успеха. Первый — удаётся ли после такого хода исключить ошибочное направление. Второй — приезжает ли в результате робот к финишу. ## Результат

На отдельной новой сотне frontier-reserve прошёл **49 карт**, каждый из двух новых агентов — **47**. Удалось пройти три прежних отказа, одновременно потеряны пять прежних финишей. Восемь пар с разным исходом дают мало оснований судить о величине эффекта в следующих сотнях. На всех 336 картах два новых агента выбрали одинаковую последовательность ходов: боковое окно ни разу не выиграло отдельный выход. Их запуски не являются двумя независимыми подтверждениями эффекта. Из исходных 36 карт, на которых в прежнем стресс-тесте не финишировал ни один из 16 контроллеров, агенты с осмотром прошли одну — H2-11 за 1200 ходов. [Исходные 36 карт](ARC-dot-unsolved.md)

**Первую часть гипотезы опыт поддерживает.** На новой сотне в 22 из 56 изменённых решений (39%) новое окно действительно сузило выбор кратчайшего подхода к сервису. Базовое предложение в тех же состояниях дало бы это в 3 случаях (5%). События внутри одного эпизода зависимы. В 19 из этих 22 случаев новая информация исключила направление, в которое робот только что поехал. В 18 случаях исключилось только оно. Для получения ответа робот уже потратил ход, иногда нужен ещё один на возврат. Выгодность разведки для финиша в целом не подтвердилась.

**На шести приобретённых картах трёх стресс-сотен ни одно новое окно в момент пробы не исключило направление по этому критерию.** В пяти из шести первый изменённый ход приблизил нужный сервис. На 14 из 16 потерянных карт первое отклонение, наоборот, увеличило показание датчика. Во всех 16 случаях и исходный, и новый выбор в момент первого расхождения ещё допускали финиш по истинной карте. Возможность пройти появившуюся траекторию исчезала позже. Новое окно также могло сообщить сведения, полезные для дальнейшего маршрута и не отражённые в показателе исключения направлений. - **check-H3-08.** На ходу 7 топлива 12, до заправки 10. База едет на юг. После возврата остаётся ровно 10 топлива на 10 ходов до заправки, и внешняя проверка показывает, что возможность совместить дальнейшие остановки утрачена уже при повороте на юг. Новый агент поворачивает на восток, единственное направление с успешным продолжением. До заправки становится 9 ходов при остатке 11. В этом окне геометрия не исключила ни одного варианта, но физический шаг приблизил нужный сервис.
- **check-H2-10.** На ходу 9 исправность 15, до мастерской 13. База едет на север. Новый агент едет на запад, где открывшаяся стена исключает западный подход. На следующем ходу он возвращается в исходную клетку уже с 13 исправности на 13 ходов пути. На ходу 19, когда остаётся 5 единиц на 5 ходов, он выбирает север, хотя финиш сохранял только запад. На ходу 23 наступает поломка. Здесь проба дала верный ответ, но полностью израсходовала запас, с которым робот подошёл бы к следующему выбору.
- **H2-17, знакомая карта.** Оба агента доехали. У базы 477 ходов и по восемь заправок и ремонтов. Новый агент на ходу 25 поехал восточнее ради обзора, исключил восточный кратчайший подход и прошёл всю карту за 69 ходов с одной заправкой и одним ремонтом. Эффект изменения маршрута виден по числу повторных заездов.

### Контроль одной пробы

После основных измерений на всех 22 стресс-картах с изменившимся фактом финиша выполнены ещё два запуска sight-route. В первом разрешена только первая проба. Во втором пропущена только первая проба, далее новые правила работают как обычно. Каждый запуск идёт от старта со штатной памятью, исходными ресурсами и физическими ходами.

При разрешении только первой пробы сохранились **все 6 приобретённых финишей** и **12 из 16 регрессий**. Пропуск первой пробы вернул **11 из 16 утраченных финишей**, из шести приобретений сохранилось одно. На новой сотне разрешение только первой пробы сохранило все три приобретения и четыре из пяти регрессий. Это контроль на картах, отобранных по разному исходу. Для переноса эффекта ограничения числа проб на остальные карты нужен отдельный опыт. [Управление первой пробой](../../results/E-0009/first_only.py) · [Все 44 дополнительных прогона](../../results/E-0009/first-only.jsonl)

Закреплённой базой остаётся frontier-reserve. Эти измерения поддерживают выбор информативного окна как способ узнать о дороге. Для дальнейшего выбора физического хода нужно оценивать также последствия ошибочного выхода. В частности, можно отдельно проверить ситуации, когда после выхода и возврата по дороге к сервису останется ещё один неподтверждённый выбор, а ресурсного запаса на него уже не будет. Новые сравнения потребуют отдельной выборки.

## Аппарат принятия решений

1. Оба новых агента сначала вычисляют команду закреплённого frontier-reserve. Если автомат уже знает посильную дорогу к финишу или кратчайшую открытую дорогу к выбранному сервису, он следует обычному правилу. Вмешательство рассматривается при движении к сервису, когда измеренная из текущей позиции длина ещё допускает несколько первых направлений.
2. Робот сравнивает окна 3×3, которые он мог бы увидеть за один ход. Для каждой пока неизвестной в них клетки проверяет гипотезу «здесь стена» на своей карте памяти. Если при этой гипотезе нижняя оценка пути через один из первых ходов становится длиннее текущего показания, такое направление отпадает. Клетка различает дороги, если отпадает часть вариантов и остаётся хотя бы один. При выборе окна важны число разных исключаемых направлений, затем число таких клеток. При равенстве сохраняется предложение базового автомата.
3. Для физической пробы требуется запас хотя бы два сверх длины пути до каждого сервиса и положительный остаток второго ресурса после предполагаемых выхода, возврата и подхода к выбранному сервису. Это проверка расходов на короткую пробу. Успешную последовательность всех последующих заездов она не гарантирует.
4. **sight-route** выбирает обзор среди ещё возможных направлений к ближайшему сервису. **sight-detour** может дополнительно сделать один боковой шаг и вернуться, если боковое окно строже различает дороги. После открытия подтверждённого маршрута к финишу этот маршрут получает приоритет перед возвратом. Агент хранит один дополнительный признак предстоящего возврата. Датчики сообщают длины только из фактической позиции. [Код двух агентов](../../maze/sight_automaton.py) · [Проверки механизма на малых примерах](../../tests/test_sight_automaton.py)

## Измерение

Физическая среда, восемь направлений движения, ресурсы, память и лимит те же у всех трёх контроллеров. Использованы 200 знакомых стресс-карт, 36 val и 100 ранее не использовавшихся карт того же генератора с seed 27110531. На новой сотне по 25 карт H1–H4. Геометрии проверены с учётом поворотов и отражений. Оба агента и протокол зафиксированы до сравнительных запусков. Обучения и итогового test SARSA здесь нет. [Отпечатки источников и выборок](../../results/E-0009/frozen.json) · [Новые карты](../../results/E-0009/fresh.jsonl)

При каждом вмешательстве наблюдатель сравнивает два окна из одной исходной позиции. Для нового агента берёт открывшиеся на самом деле клетки. Для базового предложения отдельно вычисляет, что было бы видно при исполнении той команды из той же позиции. В обоих случаях при подсчёте исключённых направлений сохраняет прежние фактические измерения датчика. Так можно выделить, что дала именно геометрия окна. Это сравнение локальных решений, в том числе после расхождения траекторий. Чем закончилось бы всё прохождение, устанавливается отдельным запуском каждого контроллера. Для первой разницы команд внешний поиск проверяет возможность финиша после каждой команды. Для изменившихся неудачных траекторий также определяется первый необратимый ход. ## Повтор запуска и просмотр

В следующем примере можно начать с пятого хода конкретной стресс-карты. Просмотр стоит на паузе, «Пуск» выполняет один ход каждые 0,5 с. Без `--visual` команда выдаёт номер хода, координаты, остатки ресурсов и длины пути до сервисов, направление, режим и окно. Для сравнения можно заменить `--agent sight-route` на `--agent reserve` или `--agent sight-detour`.

```powershell
python -B results/E-0009/replay_case.py known1 H2-11 --agent sight-route --step 5 --visual
python -B results/E-0009/replay_case.py known1 H2-11 --agent reserve --step 5 --count 4
python -m maze --split val --level val-3-01 --controller sight-route
```

Чтобы пересчитать результаты, выполнить четыре серии с новыми путями журналов в одной папке. Скрипт сводки читает файлы с именами, приведёнными ниже. Для воспроизведения на сохранённых картах используются опубликованные отпечатки и обычный Python 3.12 или новее.

```powershell
python -B results/E-0009/run.py known1 tmp/known1-episodes.jsonl
python -B results/E-0009/run.py known2 tmp/known2-episodes.jsonl
python -B results/E-0009/run.py val tmp/val-episodes.jsonl
python -B results/E-0009/run.py fresh tmp/fresh-episodes.jsonl
python -B results/E-0009/summarize.py tmp tmp/sight-summary.json tmp/sight-maps.md
```

Дополнительный контроль можно повторить командой `python -B results/E-0009/first_only.py tmp/sight-first-only.jsonl` по опубликованным журналам. Всего выполнено 1008 основных и 44 дополнительных эпизода. У базы на прежних двух сотнях и val совпали статус, число ходов, заправок и ремонтов с E-0007.
