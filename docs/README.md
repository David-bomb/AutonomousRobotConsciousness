# Документация проекта

## Где находится основная запись

| Вид сведений | Основное место | В других местах |
|---|---|---|
| Требование пользователя | `project.md` с идентификатором REQ | Короткое напоминание и ссылка |
| Обоснование проектного решения | Отдельная запись в `decisions/` | Ссылка на номер решения |
| Открытый выбор | `questions.md` с идентификатором Q | Упоминание зависимости |
| Актуальная схема системы | `architecture.md` | Ссылка, без копии интерфейса |
| Обсуждаемые варианты и их критика | `concepts/` | После выбора основание переносится в `decisions/`, требования — в `project.md` |
| Текущий прогресс | `status.md` | История завершённых этапов в `journal.md` |
| План конкретной длительной задачи | `tasks/` | Краткая ссылка из статуса |
| Протокол и результат эксперимента | `experiments/` | Вывод со ссылкой на опыт |
| Содержание статьи | `Articles/*/main_ideas.md` | Библиографическая ссылка |
| Общие научные идеи | `Articles/main_ideas.md` | Проектное решение оформляется отдельно |

Новая инструкция пользователя может изменить существующую запись. При расхождении сначала сверяется её смысл, затем обновляется основной документ и затронутые ссылки. Число повторений старой рекомендации не делает её действующим требованием.

## Статусы

- **Принято:** прямо задано пользователем или выбрано в пределах разрешённой задачи; основание указано.
- **Предложено:** вариант для обсуждения/проверки, ещё не обязательство реализации.
- **Открыто:** выбор не сделан.
- **Заменено:** прежнее решение сохранено с указанием нового.
- **Реализовано / проверено:** есть код или артефакт и конкретная проверка. Эти статусы не следуют из одного описания в документе.

Статус решения и готовность реализации ведутся раздельно.

## Как растёт структура

Исходный код, карты и спрайты находятся в [maze](../maze), проверки — в [tests](../tests). Правила и результаты первого прототипа собраны в [D-0008](decisions/0008-maze-pilot.md).

`Articles` сохраняет свою структуру и собственный Git. Вопрос охвата всего проекта системой контроля версий открыт в Q-010; создание `docs` само по себе его не решает.
