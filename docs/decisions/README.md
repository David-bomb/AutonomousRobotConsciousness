## Порядок ведения

Использовать [шаблон](../templates/decision.md) для существенного выбора. Следующий номер — `D-0009`. Имя файла начинается с того же номера без `D-`. Указание пользователя уже является основанием для фиксации решения.

Для собственного инженерного выбора отметить, какой запрос его разрешает. Для исследовательского выбора по данным — сослаться на опыт. Предлагаемый вариант сохраняется со статусом «Предложено» и не подменяет требование.

При пересмотре старую запись пометить «Заменено D-…», новую связать со старой и обновить актуальную спецификацию. Не стирать причины прежнего выбора. Небольшое уточнение текста без изменения решения не требует нового номера.
