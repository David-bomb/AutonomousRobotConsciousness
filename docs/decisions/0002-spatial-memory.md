# D-0002. Ограниченный состав пространственной памяти

- Дата: 24.09.2026.
- Статус: принято по уточнению пользователя.
- Связано с: REQ-007, REQ-009, Q-001, Q-002.
- Реализация: отсутствует.

## Основание и контекст

Пользователь уточнил: «В памяти я хочу хранить только клетки и их тип, может быть число посещений. Не более». Это заменяет первоначальное предложение ассистента хранить также время, переходы и исследованные ветви.

## Решение

Пространственная память хранит типы клеток по координатам. Число посещений допустимо, но его включение и правило счёта ещё не выбраны. Время наблюдения, давность, история переходов, стек пути, пометки тупиков/ветвей не включаются.

Отдельный журнал исследователя может содержать траекторию, но не становится доступной агенту памятью. Состав текущего состояния управления и датчиков должен быть описан явно; через них нельзя незаметно вернуть исключённую историю.

## Последствия

В обычной сетке допустимость переходов можно вычислять по типам соседей и общим правилам, если эти данные полностью определяют проходимость. Геометрию тупика можно анализировать по доступной известной карте без сохранённого ярлыка.

Хранение карты ещё не определяет, видит ли контроллер её целиком. Это Q-001. Счётчики не гарантируют отсутствия циклов и не делают любое возвращение ошибкой. Статичность среды и точность локализации пока остаются предложениями в Q-005.

## Проверка будущей реализации

Сверить поля памяти с ограничением и проверить, какие сведения фактически поступают обоим контроллерам. Не расширять состав памяти для исправления неудачного поведения без изменения постановки. Текущее описание: [architecture.md](../architecture.md).
